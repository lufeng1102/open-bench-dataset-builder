# voxpopuli-en-test-dataset

This is a 10-sample VoxPopuli English test subset generated from `voxpopuli-en-test2`.

Files:

- `df.jsonl`: dataset-level metadata updated for the 10-sample subset.
- `sf.jsonl`: sample-level metadata for the 10 selected audio files.
- `wavs/`: the 10 referenced WAV audio files.
